# 🏠 Smart Home System
### Embedded Systems Graduation Project — ITI 2025

> A fully embedded smart home controller built on AVR microcontrollers — automating lighting, temperature response, and motion detection with no external computing required.

---

## 📌 Overview

This project is a complete smart home automation system designed and implemented from scratch as a graduation project. Built entirely on **AVR microcontrollers**, the system monitors the home environment through multiple sensors and responds automatically — adjusting lighting, reacting to temperature changes, and detecting motion in real time.

Everything runs on embedded hardware with no PC or cloud dependency. The microcontroller reads sensor inputs, processes the data, and triggers the appropriate outputs — all autonomously.

---

## ⚙️ How It Works

1. **Temperature sensor** continuously monitors room temperature and triggers cooling or heating responses when thresholds are crossed
2. **Motion sensor** detects movement and activates lights or sends alerts automatically
3. **Light sensor** measures ambient brightness and adjusts artificial lighting accordingly — lights dim or brighten based on natural light levels
4. The **AVR microcontroller** acts as the central brain, processing all sensor data and coordinating every automated response in real time

---

## 🛠️ Built With

- **Microcontroller:** AVR (ATmega32 / ATmega16)
- **Language:** C
- **Sensors:** Temperature sensor, PIR motion sensor, LDR light sensor
- **Actuators:** Relays, DC motors/fans, LEDs or lamp modules
